# BBO SPDC Simulation

Bu proje, 405 nm pump ve Type-II BBO kristali kullanılarak Spontaneous Parametric Down-Conversion (SPDC) sürecini simüle eder. Kwiat tipi polarizasyon dolaşıklık kaynağı için parametrik optimizasyon, fiber kuplaj verimliliği ve hata bütçesi analizlerini içerir.

## Kurulum
Conda ortamını oluşturup aktif ettikten sonra gerekli kütüphaneleri yüklemek için:
`pip install -r requirements.txt`
